# Tarea 2: Clasificador Support Vector Machine
El propósito del código es el de estudiar y comparar clasificadores Support Vector Machine. Se utilizaran diversos kernels, en particular: lineal, polinomial y gaussiano.

## Requisitos Previos
- Cuenta de Google para acceder a Google Colaboratory.

## Instrucciones de Ejecución
1. Abrir el código en Google Colaboratory.
2. Cargar archivo Tarea_2_–_Clasificador_Support_Vector_Machine_EL4106_Diego_Vega.
3. Cargar el archivo winequality-all.csv al entorno de Google Colaboratory.
4. Ejecutar las celdas en el orden del Jupyter Notebook.

## Resultados esperados
De buenas a primeras no deberian existir fallos si los códigos se corren en el orden en el que se encuentran.
Es normal que la obtención y entrenamiento del mejor clasificador SVM con kernel polinomial se tarde algun tiempo.
Los resultados seran todos los solicitados en el archivo de las instrucciones de la tarea 2.

## Dependencias y Librerías
Todas las librerias a utilizar se encuentran disponibles en el entorno de Google Colaboratory (no es necesario hacer un pip install).
Las librerias a utilizar son:
1. Pandas
2. Numpy
3. Matplotlib (pyplot)
4. Sklearn (model_selection, preprocessing, svm y metrics)
5. Time
