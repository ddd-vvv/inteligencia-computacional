# Tarea 3: Selección de Características
El propósito del código es el de estudiar y comparar selectores de características.
Se utilizaran dos tipos de clasificadores Support Vector Machine con kernel lineal y RandomForest.
Se utilizaran dos tipos de selectores: wrapper y filtro.

## Requisitos Previos
- Cuenta de Google para acceder a Google Colaboratory.

## Instrucciones de Ejecución
1. Abrir el código en Google Colaboratory.
2. Cargar archivo Tarea_3_–_Selección_de_Características_EL4106_Diego_Vega.ipynb .
3. Cargar el archivo processed.cleveland.data al entorno de Google Colaboratory.
4. Ejecutar las celdas en el orden del Jupyter Notebook.

## Resultados esperados
De buenas a primeras no deberian existir fallos si los códigos se corren en el orden en el que se encuentran.
Los resultados seran todos los solicitados en el archivo de las instrucciones de la tarea 3.

## Dependencias y Librerías
Todas las librerias a utilizar se encuentran disponibles en el entorno de Google Colaboratory (no es necesario hacer un pip install).
Las librerias a utilizar son:
1. Pandas
2. Numpy
3. Matplotlib (pyplot)
4. Sklearn (model_selection, preprocessing, svm y metrics)
5. Time
6. Seaborn
